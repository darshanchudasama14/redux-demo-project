A clean and scalable React Native CLI starter project built with TypeScript, Redux, React Navigation, and simple REST API integration.

## Features

- React Native CLI
- TypeScript
- Redux Toolkit
- React Navigation
- REST API Integration (Fetch API)
- Authentication Flow
- Redux State Management
- Reusable Components
- Custom Theme & Colors
- Responsive UI
- Image Assets Management
- Search Functionality
- Favorites Management
- Clean Folder Structure
